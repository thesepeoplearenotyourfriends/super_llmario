Directives: @pipe A -> B, @pipe A <-> B, @pipe A -> COL,ROW (pipes are lettered by mouth column, then row); @at COL,ROW key=value… sets parameters on the object covering that cell; @place PLACEABLE COL ROW key=value… adds anything else at its anchor; @start/@goal COL ROW; @world X Y W H.

Editor help

  • Choose a palette card to place it; click an active multi-form card again to cycle its authored forms.
  • Stamp: drag an active Block or Brick brush across snapped cells; occupied cells are skipped.
  • Eraser: removes objects only while you drag and locks each drag to the layer of the first object erased.
  • Click an object or marker to select it and leave placement mode. Click empty canvas to select none.
  • Copy / paste: Ctrl/Cmd+C copies the selected object, Ctrl/Cmd+X cuts it, Ctrl/Cmd+V pastes it with its anchor at the pointer (again on the same spot steps one cell along). The copy is selected, ready to drag.
  • Drag a selected object or marker to move it. Drag an object's gold resize handle to resize it.
  • With no brush active, drag empty canvas to pan. Use the wheel to zoom around the pointer.
  • Palette and Details independently show or hide their sidebars.
  • Open and Save use standalone map files. Ctrl/Cmd+Z undoes; Ctrl/Cmd+Shift+Z or Ctrl/Cmd+Y redoes.
  • Delete/Backspace removes the selected instance or marker.
  • Start and Goal cards place grid-snapped singleton markers; placing another replaces the existing marker.

This editor authors one current map. It does not simulate gameplay.
